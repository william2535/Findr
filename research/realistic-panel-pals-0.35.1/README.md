# Real portrait Panel Pals

The six scientist choices now use real public-domain photographs or paintings. OG and Panel pal retain their original icons. IDs, older-icon migration, selected colours and saved conversations are unchanged.

Images are bundled with the offline app; there are no runtime requests to Wikimedia. The six files total 299157 bytes. Face crops are applied at display time, with the existing vector silhouette behind the image as a load fallback. The source files were not edited or regenerated.

- **Lovelace** — Alfred Edward Chalon. [File:Ada Lovelace portrait.jpg](https://commons.wikimedia.org/wiki/File:Ada_Lovelace_portrait.jpg). Wikimedia Commons identifies the work as public domain; metadata checked 11 November 2026.
- **Einstein** — Photograph by Orren Jack Turner, Princeton, N.J. Modified with Photoshop by PM_Poon and later by Dantadd.. [File:Albert Einstein Head.jpg](https://commons.wikimedia.org/wiki/File:Albert_Einstein_Head.jpg). Wikimedia Commons identifies the work as public domain; metadata checked 11 November 2026.

- **Hawking** — NASA. [File:Stephen Hawking.StarChild.jpg](https://commons.wikimedia.org/wiki/File:Stephen_Hawking.StarChild.jpg). Wikimedia Commons identifies the work as public domain; metadata checked 11 November 2026.
